**ОСНОВНЫЕ ТЕРМИНЫ:**

**Объектно Ориентированное Программирование (ООП)** - это подход к программированию, где программа строится из объектов (кусочков кода), каждый из которых хранит данные и умеет выполнять действия с ними.

**Принципы ООП следующие:**
**Инкапсуляция** — «Спрячь детали внутрь, а снаружи оставь только кнопки для управления» (объект скрывает внутреннее устройство и даёт доступ лишь через чётко определённые методы).

**Наследование** — «Возьми готовое и дополни своим» (новый класс перенимает свойства и поведение существующего, добавляя что‑то своё).

**Полиморфизм** — «Одно имя — разное поведение» (один и тот же метод работает по‑разному в зависимости от того, к какому объекту его применяют).

**Абстракция** — «Покажи только самое важное, остальное спрячь» (объект предоставляет упрощённое представление, скрывая сложные детали реализации).


**Класс** - это некий чертёж, который содержит набор команд (Методов), набор переменных и полей. Это основа, без которой код не будет работать (грубо говоря, класс - это автомобиль, методы внутри класса - компоненты (двигатель, сигнализация и др.)

**Переменная** - именнованая часть кода, которая может хранить в себе временный результат или значение, которое постоянно перезаписывается (при каждом выполнении метода) **(ПЕРЕМЕННУЮ МОЖНО ОБЪЯВИТЬ ТОЛЬКО ВНУТРИ МЕТОДА)**

**Поле** - по сути та же переменная, но она используется глобально (то есть объявляется за пределами метода), отличие переменной от поля в том, что поле хранит информацию до полного завершения кода, а переменная моежт изменяться при каждом выполнении метода

**Метод** - это блок кода, выполняющий какую-либо функцию

**Модификатор доступа** - ключевое слово в языке программирования, которое определяет, из каких частей программы можно обращаться к классу, методу, полю или другому элементу кода (кто «имеет доступ»).

**Модификаторы бывают нескольких типов (я покажу те, которые показывал Гордин):**

**private** - приватный модификатор, говорит о том, что все данные, находящиеся в пределе данного кода, нельзя будет наследовать
**public** - говорит о том, что мы можем наследовать и использовать данный код в любых других классах
**protected** - позволяет использовать данный код только в тех классах, которые наследуют класс, в котором есть модификатор protected, если этого класса нет, будет ошибка.

**Параметр возврата** - благодаря данному параметру, мы можем вернуть какой-либо результат после выполнения метода, результат зависит от типа данных параметра

**ТИПЫ ДАННЫХ**

**int** — целочисленный тип (32 бита), хранит числа от −2 147 483 648 до 2 147 483 647.
**long** — длинное целое (64 бита), диапазон: от −9 223 372 036 854 775 808 до 9 223 372 036 854 775 807.
**short** — короткое целое (16 бит), хранит числа от −32 768 до 32 767.
**byte** — беззнаковое 8‑битное целое, значения от 0 до 255.
**sbyte** — знаковое 8‑битное целое, диапазон: от −128 до 127.
**ulong** — беззнаковое длинное целое (64 бита), от 0 до 18 446 744 073 709 551 615.
**ushort** — беззнаковое короткое целое (16 бит), от 0 до 65 535.
**uint** — беззнаковое 32‑битное целое, от 0 до 4 294 967 295.
**float** — число с плавающей точкой (32 бита), точность ~7 знаков.
**double** — число с плавающей точкой (64 бита), точность ~15–16 знаков.
**decimal** — десятичный тип (128 бит) для точных финансовых расчётов, до 28–29 знаков.
**bool** — логический тип, принимает значения true или false.
**char** — одиночный символ Unicode (16 бит), например 'A', '€'.
**string** — последовательность символов Unicode (строка), например "Привет".
**object** — базовый тип для любого значения/объекта, может хранить экземпляр любого типа.
**var** — ключевое слово для неявного вывода типа переменной (компилятор сам определяет тип по значению).
**struct** - пользовательский тип данных, например, в нём может храниться несколько полей с типом string ( грубо говоря, структура это модель данных, как в таблице (мы создаём поля, которые будут являться ячейками в таблице,
и передав какие-либо значения в данную структуру, мы соответственно выведем информацию (ниже будут примеры со структурой))

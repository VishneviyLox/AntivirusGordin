Этот документ содержит базовую теорию по языку C# и платформе .NET, которая используется в коде приложения VirusGordin. Мы будем использовать максимально простые объяснения и примеры, чтобы материал был понятен даже новичку.

1**. Что такое C# и .NET?**
C# (Си-Шарп) 💻: Это современный, объектно-ориентированный язык программирования, разработанный компанией Microsoft. Он используется для создания самых разных приложений: для Windows, веба, мобильных устройств и игр (Unity).

.NET (Дот-НЕТ): Это большая программная платформа (фреймворк), которая включает в себя библиотеки, инструменты и среду выполнения (место, где код запускается). C# — основной язык для .NET.

Windows Forms (WinForms): Это технология внутри .NET, которая позволяет легко создавать графические приложения (окна, кнопки, таблицы) для Windows, как наше приложение-антивирус.

**2. Структура Кода (Классы, Методы, Пространства имён)
2.1. Пространство имён (Namespace)**
Это контейнер, который помогает организовать код и избежать конфликтов имён.

**В коде:** namespace VirusGordin

**Простое объяснение:** Представьте, что это папка на компьютере. Все, что находится внутри, относится к проекту "VirusGordin".

**2.2. Класс (Class)**
**Класс** — это "чертеж" для создания объектов. Он определяет, какие данные (поля) и какие действия (методы) будет иметь объект.

**В коде:** public partial class Form1 : Form

П**ростое объяснение:** Form1 — это чертеж главного окна нашего приложения. : означает, что Form1 наследует (получает все возможности) от базового класса Form (стандартное окно Windows).

**2.3. Метод (Method)**
**Метод** — это блок кода, который выполняет определенное действие. По сути, это функция.

**В коде:
**
**public Form1():** Конструктор. Специальный метод, который вызывается, когда мы создаем новый объект Form1. Он "собирает" окно.

**void Form1_Load(object sender, EventArgs e):** Вызывается, когда окно впервые загружается и готово к работе.

**void Read():** Метод, который обновляет таблицу (DataGridView) на экране.

**void ScanFolderBtn_Click(...):** Метод, который выполняется при нажатии на кнопку "Сканировать".

**3. Хранение Данных (Поля, Списки и Структуры)
3.1. Поля (Fields)**
Переменные, объявленные внутри класса, называются полями. Они хранят данные, к которым могут обращаться все методы класса.

**3.2. Списки (List<T>)**
**Список** — это коллекция, которая может хранить много объектов одного типа. Это как динамический массив (его размер может меняться).

**В коде:**

List<Signature> _signature = new List<Signature>();: Список для хранения всех вирусных сигнатур (база данных).

List<string> virusFile = new List<string>();: Список для хранения путей к зараженным файлам.

**Простое объяснение:** List<Signature> — это "коробка", куда можно складывать только объекты типа Signature.

**3.3. Структуры (struct)**
Структура используется для объединения нескольких связанных переменных в один логический блок.

**В коде:**

struct Signature
{
    public string ViruceName; // Название вируса
    public string SignatureName; // Кусок кода (сигнатура)
    // ... другие поля
}
**Простое объяснение:** Структура Signature объединяет три разные характеристики (название, сигнатура, описание) в одну удобную сущность.

**4. Работа с Файлами и Папками (Классы System.IO)**
В C# для работы с файловой системой (чтение, запись, удаление) используются классы из пространства имён System.IO.

**4.1. Чтение Файлов (StreamReader)
Используется для последовательного чтения данных из файла (текста).**

**В коде:**

StreamReader stream = new StreamReader(item); // Открывает файл
string read = stream.ReadToEnd();             // Читает всё содержимое в одну строку
stream.Close();                              // Закрывает файл
Простое объяснение: Мы "открываем трубу" (StreamReader) к файлу, "выкачиваем" из него весь текст (ReadToEnd()), а затем "закрываем трубу" (Close()), чтобы не блокировать файл.

**4.2. Поиск Файлов (Directory.GetFiles)**
Класс Directory предоставляет статические методы (те, что вызываются без создания объекта) для работы с папками.

**В коде:**

string[] search = Directory.GetFiles(folderBrowserDialog.SelectedPath, "*.txt");
Объяснение: Этот метод ищет все файлы в указанной папке (SelectedPath) с расширением *.txt и возвращает их полные пути в виде массива строк (string[]).

**4.3. Удаление Файлов (File.Delete)**
Класс File предоставляет статические методы для работы с отдельными файлами.

**В коде:** File.Delete(path);

Объяснение: Безоговорочно удаляет файл по указанному полному пути (path).

**5. Логика Антивируса: Поиск Сигнатур**
Основная логика сканирования находится в методе ScanFolderBtn_Click.

**Перебор Файлов:**

foreach (string item in search) // Для каждого найденного файла *.txt...
{
    // ... читаем его содержимое
    string read = stream.ReadToEnd();
    // ...
}
**Перебор Сигнатур:**

foreach (var st in _signature) // Для каждой вирусной сигнатуры в нашей базе...
{
    // ПОИСК СИГНАТУРЫ:
    if (read.IndexOf(st.SignatureName) != -1) // Проверяем, есть ли сигнатура внутри текста файла
    {
        // Вирус найден!
        InfectedFileWrite(item, st);
    }
}
**Метод IndexOf():** Это строковый метод. Он ищет одну строку (st.SignatureName) внутри другой строки (read - содержимое файла). Если строка найдена, он возвращает её позицию (число). Если НЕ найдена, он возвращает -1. Поэтому, если результат не равен -1, значит, вирусная сигнатура найдена.
